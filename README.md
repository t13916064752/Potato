# AI 生图工作台

一个只给自己本地使用的 GPT 图片生成界面。它提供提示词输入、常用比例 / 分辨率、生成数量、质量和背景选项，并在浏览器本地保存最近的生成历史。

## 使用方式

1. 设置 OpenAI API Key：

   ```bash
   export OPENAI_API_KEY="你的 API Key"
   ```

2. 启动本地服务：

   ```bash
   npm start
   ```

3. 打开浏览器访问：

   ```text
   http://localhost:3000
   ```

## 功能

- 使用 `gpt-image-1` 生成图片。
- 支持 `1024x1024`、`1536x1024`、`1024x1536` 和自动尺寸。
- 支持一次生成 1 到 4 张图片。
- 支持自动、低、中、高质量选项。
- 支持自动、不透明、透明背景选项。
- 图片历史保存在当前浏览器的 `localStorage`，可直接下载 PNG。
